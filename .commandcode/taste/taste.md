# Taste

## Engineering / data sources
- Prefers reliable, accurate data sources over quick/convenience fixes, even when the accurate option requires more setup (e.g., choosing authenticated GitHub GraphQL API over a free third-party scraper API). Confidence: 0.8
- Prefers keeping API tokens/credentials secure in server-side or CI secrets rather than exposing them in client-side code. Confidence: 0.75

## UI / Data visualization
- Prefers contribution/activity graphs to follow the familiar GitHub-style orientation: time flows horizontally (each week = one column, 7 weekday rows), not vertically stacked — data widgets should match the source platform's conventional layout. Confidence: 0.75
